# 🚗 PARK-AI — Smart Parking Allocation System

**Making parking smarter, simpler, and more convenient.**

PARK-AI is a web-based Smart Parking Allocation System designed to help users find suitable parking spaces based on their vehicle type and parking requirements. It provides an interactive dashboard, visual parking map, slot recommendations, reservations, digital parking tickets, parking-session tracking, statistics, alerts, and an integrated PARK-AI Assistant.

## 📌 Project Overview

Finding a suitable parking space can be time-consuming and inconvenient. PARK-AI aims to simplify the parking experience by bringing essential parking features together in one interface.

Users can explore parking slots, select their requirements, view recommended spaces, reserve a slot, and access parking-session information through an intuitive dashboard.

## ✨ Key Features

### 1. 📊 Interactive Dashboard
- Provides a central overview of parking activity.
- Offers access to the main application modules.
- Displays parking information and controls.

### 2. 🗺️ Smart Parking Map
- Visually represents individual parking slots.
- Distinguishes available and occupied spaces.
- Highlights the recommended slot after selection.

### 3. 🚘 Find the Best Parking Slot
- Supports different vehicle types, including cars, bikes, SUVs, and electric vehicles (EVs).
- Allows users to specify requirements such as EV charging, accessible parking, and proximity to the entrance.
- Displays a recommended parking space based on the selected requirements.

### 4. 🎫 Reservation and Digital Ticket
- Provides a slot reservation interface.
- Displays parking and vehicle details on a digital ticket.
- Includes a QR-code area intended for potential future exit-system integration.

### 5. ⏱️ Parking Timer and Fee Estimation
- Displays information about the selected parking slot.
- Shows parking-session timing.
- Presents an estimated parking fee to help users understand potential costs.

### 6. 📈 Statistics and Alerts
- Presents parking occupancy information and related statistics.
- Displays selected-slot information and parking analytics.
- Supports alerts for conditions such as high occupancy, EV charging, zone availability, and slot status.

### 7. 🤖 PARK-AI Assistant
- Provides an integrated assistant interface for parking-related help.
- Helps users navigate the application and understand its features.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PARK-AI-Smart-Parking.git
   ```

2. Open the project folder:

   ```bash
   cd PARK-AI-Smart-Parking
   ```

3. Open `index.html` in your browser.

4. Alternatively, open the project in Visual Studio Code and use the **Live Server** extension.

**Note:** Replace `YOUR-USERNAME` with your GitHub username before running the clone command.
